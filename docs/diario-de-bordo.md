# Diário de Bordo - FlexBox Trainer

Este arquivo é o registro oficial da evolução do projeto. A equipe deve atualizar aqui o que foi feito em cada dia ou reunião, para manter o histórico claro para a apresentação do TCC e para a organização do trabalho em grupo.

## Objetivo do Diário

Registrar, de forma simples e padronizada:

- o que foi desenvolvido;
- o que foi aprendido;
- quais dificuldades apareceram;
- qual é o próximo passo.

## Como Usar

1. Adicione uma nova entrada a cada dia de trabalho ou reunião importante.
2. Use linguagem objetiva.
3. Escreva apenas o que realmente aconteceu.
4. Se houver decisão de arquitetura, anote aqui.
5. Se houver problema técnico, descreva o erro e a solução encontrada.

## Modelo de Entrada

Use sempre este formato:

```md
Data: AAAA-MM-DD
Autores: Nome 1, Nome 2

O que fizemos hoje:

-

O que aprendemos:

-

Dificuldades:

-

Próximo passo:

-
```

## Regras de Preenchimento

- Cada entrada deve ter data.
- Cada entrada deve ter os nomes de quem participou.
- Evite texto muito longo.
- Prefira tópicos curtos.
- Se algo foi decidido em grupo, explique o motivo da decisão.
- Se algo foi implementado no código, cite o arquivo quando for útil.

## Sugestão de Organização

Para manter o histórico legível, siga esta ordem:

1. Data da entrada.
2. Participantes.
3. Atividades realizadas.
4. Aprendizados.
5. Dificuldades.
6. Próximos passos.

## Exemplo de Entrada

```md
Data: 2026-05-04
Autores: Equipe FlexBox Trainer

O que fizemos hoje:

- Organizamos a estrutura inicial da extensão no VS Code.
- Definimos que o usuário vai editar index.html e style.css no editor normal.

O que aprendemos:

- O fluxo com Webview lateral e leitura da workspace funciona para o objetivo do projeto.

Dificuldades:

- Integração com o webservice oficial ainda depende da documentação final.

Próximo passo:

- Registrar o contrato do webservice assim que o professor apresentar.
```

## Modelo de Responsabilidade

- Se você desenvolveu algo, registre no diário no mesmo dia.
- Se você revisou código de outro colega, registre a revisão.
- Se houve reunião com orientação, registre os pontos principais.
- Se houve bloqueio, registre o que impediu o avanço.

## Dica Para o Time

Mantenham o diário como um arquivo vivo. Ele deve ajudar qualquer pessoa da equipe a entender rapidamente o que já foi feito, o que falta fazer e quais decisões já foram tomadas.
